# CoachDesk — Project Status Document

**Prepared:** November 2026 · **Version:** 2.0 · **Project:** CoachDesk SaaS Coaching Institute Management System

---

## 1. Our Agenda

Build **CoachDesk** — a production-grade, multi-tenant SaaS platform for Indian coaching institutes, tuition centres, and training academies. Each institute operates independently while sharing one unified infrastructure, letting them manage students, batches, attendance, fees, exams, staff, and parent communication from a single dashboard.

**Core goals:**
- **Multi-tenant isolation** — one platform, many institutes, zero data leakage
- **Enterprise security** — session + JWT auth, RBAC, audit logging, password reset flows
- **Complete SaaS lifecycle** — public signup → trial → subscription → billing
- **Scalable foundation** — small tuition centres today, multi-branch institutes tomorrow
- **Dual frontends** — server-rendered CI4 admin (live) + React SPA (upcoming)

**Technology stack (locked in):**
- **Backend:** PHP 8.1+ / CodeIgniter 4 (HMVC), MySQL 8, no ORM
- **Auth:** Session (admin UI) · JWT + refresh tokens (API) · Password reset via email tokens
- **Frontend:** React + Vite + TypeScript + Tailwind + shadcn/ui *(upcoming)*
- **Email:** SendInBlue (via `NexusSendEmail` helper) · branded inline-CSS templates
- **PDF:** DomPDF (tenant-branded receipts)
- **Table prefix:** `cd_` · **API base:** `/api/v1` · **Admin base:** `/admin`

## Dependencies & Risks

| Risk | Mitigation |
|---|---|
| **SendInBlue email quota** | Fallback SMTP provider; monitor daily sends |
| **WhatsApp API rate limits** | Queue system (Redis + worker) |
| **Payment gateway compliance** | PCI-DSS via Razorpay hosted checkout |
| **Multi-tenancy leak** | Automated cross-tenant tests in CI |
| **Data privacy (Indian DPDP Act)** | Consent capture, data export, retention policy |
| **PHP 7.4 fallback** | Polyfills in place; **upgrade to PHP 8.2 required before public launch** |
| **Scaling DB >2B rows** | Migrate `INT(11)` → `BIGINT` when approaching limit |
| **DomPDF rendering** | Test at production scale; fallback to wkhtmltopdf if needed |
