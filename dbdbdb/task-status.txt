# CoachDesk — Project Status Document

**Prepared:** November 2026 · **Version:** 1.0 · **Project:** CoachDesk SaaS Coaching Institute Management System

---

## 1. Our Agenda

Build **CoachDesk** — a production-grade, multi-tenant SaaS platform for Indian coaching institutes, tuition centres, and training academies. The platform lets each institute independently manage students, batches, attendance, fees, exams, staff, and parent communication from a single unified dashboard.

**Core goals:**
- **Multi-tenant isolation** — one platform, many institutes, zero data leakage
- **Enterprise security** — JWT + session auth, RBAC, audit logging, encryption
- **Complete SaaS lifecycle** — signup → trial → subscription → billing
- **Scalable foundation** — start with small centres, scale to multi-branch institutes
- **Dual frontends** — server-rendered CI4 admin + React SPA (API-driven)

**Technology stack (locked in):**
- **Backend:** PHP 8.1+ / CodeIgniter 4 (HMVC), MySQL 8, no ORM
- **Auth:** JWT + refresh tokens (API) · session (admin UI)
- **Frontend:** React + Vite + TypeScript + Tailwind + shadcn/ui *(upcoming)*
- **Table prefix:** `cd_` · **API base:** `/api/v1` · **Admin base:** `/admin`

## Dependencies & Risks

| Risk | Mitigation |
|---|---|
| **SendInBlue email quota** | Add fallback SMTP, monitor daily sends |
| **WhatsApp API rate limits** | Queue system (Redis + worker) |
| **Payment gateway compliance** | PCI-DSS via Razorpay hosted checkout only |
| **Multi-tenancy leak** | Automated cross-tenant tests in CI |
| **Data privacy (Indian DPDP Act)** | Consent capture, data export, retention policy |
| **PHP 7.4 fallback** | Current polyfills in place; **upgrade to PHP 8.2 required before public launch** |
| **Scaling DB >2B rows** | Migrate `INT(11)` → `BIGINT` when approaching limit |
